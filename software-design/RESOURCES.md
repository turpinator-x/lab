# Resources

## A Philosophy of Software Design (Ousterhout)
- [Talk: "A Philosophy of Software Design", John Ousterhout, Talks at Google](https://www.youtube.com/watch?v=bmSAYlu0NcY): the author presenting the book's core ideas; best free primary source.
- [Ousterhout CS 190: Modular Design notes](https://web.stanford.edu/~ouster/cgi-bin/cs190-spring16/lecture.php?topic=modularDesign): interface vs implementation, information hiding, thin vs thick classes, classitis. Used in lesson 1.
- [Ousterhout CS 190: The UNIX Time-Sharing System notes](https://web.stanford.edu/~ouster/cgi-bin/cs190-spring16/lecture.php?topic=unix): Unix file I/O as the deep-module example. Used in lesson 1.
- [Author's book page, Stanford](https://web.stanford.edu/~ouster/cgi-bin/book.php): official page with the table of contents.

## Domain-Driven Design (Evans)
- [Domain-Driven Design Reference, Eric Evans (domainlanguage.com)](https://www.domainlanguage.com/ddd/reference/): the author's free, short summary of the book's patterns.
- [Martin Fowler: Ubiquitous Language](https://martinfowler.com/bliki/UbiquitousLanguage.html)
- [Martin Fowler: Bounded Context](https://martinfowler.com/bliki/BoundedContext.html)

## Working Effectively with Legacy Code (Feathers)
- [Martin Fowler: Legacy Seam](https://martinfowler.com/bliki/LegacySeam.html): defines seams and enabling points with a worked example. Used in lesson 4.
- [InfoQ: Understanding Legacy Code with Characterization Testing](https://www.infoq.com/news/2007/03/characterization-testing): summary of Feathers' idea and heuristics (secondary source). Used in lesson 4.
- Still no free primary source from Feathers himself; the book is the original.
