"How do you keep AI-written code good?"

Your answer, in four habits

You already know the pieces. This lesson ties them into one short story for an interview.

  1. Deep modules. Small interface, lots hidden. Run the deletion test on anything the agent adds. (Lesson 1)
  2. One place per fact. Things that change together live together. (Lesson 2)
  3. One written language. One word per concept, in a glossary the agent reads. (Lesson 3)
  4. Pin and compare. Pin today's behavior, let the agent change it, compare. Use a seam to test fast. (Lesson 4)

Habits 1 to 3 shape the code before the agent works. Habit 4 checks it after. That before-and-after split is a good way to say it.
