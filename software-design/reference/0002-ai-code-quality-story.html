Keeping AI-written code good

Before the agent works (shape the code):

1. Deep modules. Small interface, lots hidden. Deletion test: does complexity vanish (pass-through) or reappear in callers (earns its keep)?
2. One place per fact. Bring together what shares information or changes together.
3. One written language. One word per concept. Glossary with words to avoid. New context where the language changes.

After the agent works (check it):

4. Pin and compare. Characterization test of today's behavior, change, rerun. Seam where the code calls the outside world. Timing check for speed. Roll back on regress.
